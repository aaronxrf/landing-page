About

Sveiki, mani sauc Romāns!

Esmu Transporta un sakaru institūta (TSI), Rīgā, absolvents ar inženierzinātņu maģistra grādu informācijas sistēmu vadībā. Pašlaik strādāju kā IT vadītājs (DevOps/infrastruktūra), fokusējoties uz modernizāciju, automatizāciju un uzticamību.

Ko es varu

  • Linux administrēšana un automatizācija
  • On‑prem infrastruktūra un vSphere
  • Kubernetes (containerd) uzturēšana
  • GitOps un CI/CD pipeline
  • Slepeno datu pārvaldība un drošība
  • Problēmu analīze un risināšana

Pieredze

Uzticamība un darbību modernizācija

Vadīju infrastruktūras uzlabojumus, standartizāciju un automatizāciju, samazinot manuālo darbu un uzlabojot pakalpojumu kvalitāti Linux un virtualizācijas vidēs.

GitOps un droša piegāde

Ieviesu GitOps ar FluxCD, optimizēju CI/CD pipeline un izmantoju SOPS šifrēšanai Git repozitorijos, nodrošinot prognozējamas izvietošanas.

Kubernetes uzturēšana un incidenti

Uzturēju containerd‑balstītus Kubernetes klasterus, veicu izvietošanu, atjaunināšanu un incidentu risināšanu, saglabājot stabilu darbību.
